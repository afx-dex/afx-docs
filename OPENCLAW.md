# OpenClaw Instructions For AFX DEX

AFX DEX exposes REST, WebSocket, SDK, and signing artifacts for agentic development.

Recommended read order:

1. `llms.txt`
2. `afx-api/agent-guides/first-trade.md`
3. `afx-api/artifacts/openapi.json`
4. `afx-api/artifacts/asyncapi.json`
5. `afx-api/artifacts/schemas/signed-actions.schema.json`

Use official SDKs when possible. Keep all secrets in environment variables and prefer testnet for first execution.
